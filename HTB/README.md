# Hack The Box Machines

This repository contains write-ups of various machine challenges completed on [HackTheBox.com](https://www.hackthebox.com/). The write-ups are orgranized by the difficulty listed on HTB.

---

## Environment

These challenges were completed on a Lenovo ThinkPad E14 running Linux Mint with i3. For access to tooling better suited to forensic and pentesting work, I used a Kali XFCE virtual machine, especially for challenges involving SSH or other remote access.

> Notes:
>
> Connecting via OpenVPN is detailed in the first write-up, **Meow**.
>
> Adding the target IP to `/etc/hosts` using the shorthand `<challengeName>.htb` is detailed in **Kobold**.

## Notes

These write-ups are intended to document methodology, enumeration flow, and reasoning throughout each machine rather than simply listing commands. Where relevant, false starts and dead ends are also included to better reflect the actual problem-solving process.
